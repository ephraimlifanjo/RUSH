RUSH focuses on the formats people use every day instead of becoming another oversized office package. PDF workflows and text documents share one consistent desktop experience.

PDF STUDIO

Edit, organize, search and protect PDFs.

Open ordinary or scanned PDFs, work page by page, annotate, fill, sign, protect and convert — without uploading the document to a remote service.

  • Edit text regions and add text
  • Highlight, underline, strikeout and comments
  • Fill PDF forms and place signatures
  • Merge, split, crop, rotate and reorder pages
  • OCR-powered search for scanned PDFs
  • Redaction, encryption, compression and metadata tools
DOCUMENT EDITOR

Create polished office documents.

A focused rich-text workspace for reports, invoices, letters, CVs, invitations and everyday office writing with local file support.

  • DOCX, ODT, RTF and TXT editing
  • Bold, italic, underline, color and fonts
  • Paragraph alignment, lists and spacing
  • Tables, images, links and page layout
  • Headers, footers, page numbering and find/replace
  • Export documents to PDF or HTML
PRODUCT EXPERIENCE

A desktop UI designed for real work.

Dark collapsible navigation, a clean light workspace and RUSH red accents keep high-frequency tools visible without overwhelming the document.

PRIVACY FIRST

Your files are work product,
not cloud telemetry.

RUSH is designed around local processing. A dedicated Nova Studio cloud backend is not required to open, edit, search or organize your documents.

01

Local by default

PDF and document operations run on the device whenever the required local engine is available.

02

No document account

Users do not need to create an online account simply to work with their own local files.

03

Controlled resource use

Lazy thumbnails, bounded OCR work and isolated engine processes reduce unnecessary memory and CPU usage.

04

Local indexing

SQLite full-text search and optional DuckDB analytics can index large libraries without shipping file contents to a cloud database.
