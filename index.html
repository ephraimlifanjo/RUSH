PROFESSIONAL PDF WORKSPACE

Built for the document, not for clutter.

RUSH keeps pages, editing tools and properties visible together. The sidebar collapses when you need more space, while high-frequency tools stay one click away.

LOCAL BY DEFAULT

Your work stays on your device.

PDF rendering, document editing, OCR, local indexing and most conversion work are designed to run on the computer. Secure HTTPS import blocks local-network targets and enforces file type and size limits.

Local processingFiles do not need to be uploaded to RUSH servers.
Version historyLocal snapshots can preserve previous file versions.
Signed Pro licensesDirect licenses are verified with a public key; store builds can use store entitlements.
Tamper-evident releasesRelease signing and integrity manifests are supported. No desktop app is honestly “unhackable”.
